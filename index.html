01 The Problem

A college bus must start at the college, visit every required pickup location, collect students without exceeding capacity, minimise total travel distance, and return to the college. Choosing the visiting order is a Travelling Salesman Problem (TSP) with a capacity feasibility constraint — with n pickups there are n! possible orders, so the choice of algorithm matters.
